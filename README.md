# ✦ Edith – A Modern Desktop Web Browser

**Edith** is a stylish desktop web browser developed using Python, PyQt5, and Qt WebEngine. It features a custom-designed homepage with an elegant dark-purple interface, integrated Google search, live clock, quick-access website shortcuts, and essential browsing controls.

Designed with simplicity and aesthetics in mind, Edith provides a personalized browsing experience through a lightweight desktop application.

## ✨ Features

- **Custom Homepage:** Beautifully designed homepage with Edith branding and a dark-purple gradient theme.
- **Modern UI:** Minimal and elegant interface with lavender accents, rounded search bar, and smooth styling.
- **Web Browsing:** Browse websites directly within the desktop application.
- **Google Search Integration:** Search the web directly from the homepage or address bar.
- **Navigation Controls:** Back, Forward, Reload, and Home buttons.
- **Live Clock and Date:** Displays the current time and date on the homepage.
- **Quick Access Shortcuts:** Direct links to Google, YouTube, GitHub, LinkedIn, and Gmail.
- **Address Bar:** Enter website URLs or search queries.
- **Loading Indicator:** Displays page-loading progress.
- **Keyboard Shortcuts:** Convenient keyboard navigation.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/kawiyasri/Edith.git
```

### 2. Navigate to the Project Directory

```bash
cd Edith
```

### 3. Install Dependencies

```bash
pip install PyQt5 PyQtWebEngine
```

### 4. Run the Application

```bash
python edith_browser.py
```

The Edith browser will launch with its custom-designed homepage.

| Shortcut | Action |
|---|---|

| `Alt + Right` | Go Forward |
| `Ctrl + R` | Reload Page |
| `Alt + Home` | Open Edith Homepage |
